MYSTERY SHOP — The Secret of Hidden Prices
Media pembelajaran SPLDV dengan GeoGebra (mode demonstrasi satu kelas)

CARA MENJALANKAN
1. Ekstrak folder mystery_shop jika diunduh sebagai ZIP.
2. Klik dua kali index.html atau buka melalui browser Chrome/Edge.
3. Layarkan ke proyektor, lalu klik Mulai bermain.

CARA MEMAINKAN (DEMONSTRASI)
- Satu orang (penyaji) mengoperasikan laptop; seluruh kelas ikut menebak dan menjawab bareng-bareng.
- Di setiap level, minta kelas menebak model matematika dari struk lebih dulu.
  Setelah itu klik "Tampilkan model matematika" untuk mencocokkan.
- Ketik persamaan di GeoGebra, cari titik potong, lalu masukkan jawabannya.
- Di Level 3, kelas harus mengingat harga dari Level 1 dan 2. Tombol "Buka catatan harga Miko"
  bisa dipakai sebagai bantuan.

CATATAN GEOGEBRA
- Game memuat GeoGebra Graphing Calculator melalui iframe (dimuat saat levelnya dibuka).
- Dibutuhkan koneksi internet untuk memuat GeoGebra dan Google Fonts.
- Jika iframe tidak muncul karena pembatasan jaringan/browser, gunakan tautan "buka GeoGebra di tab baru".

JAWABAN PENYAJI (jangan ditampilkan ke kelas)
Level 1: 2x + y = 16 ; x + 2y = 14  -> x=6, y=4 (ribuan rupiah).
Level 2: 3x + 2y = 23 ; x + y = 9   -> x=5, y=4 (ribuan rupiah).
Final checkout: 3 pensil + 2 buku + 2 apel + 3 jeruk = 18.000 + 8.000 + 10.000 + 12.000 = Rp48.000.

SKOR
Skor untuk satu kelas. Setiap misi memberi 100 poin pada percobaan pertama atau 70 poin jika perlu mencoba lagi.
Skor maksimum: 300 poin. (Mengisi kolom kosong tidak dihitung sebagai percobaan.)

PUBLIKASI GITHUB PAGES
1. Buat repository GitHub baru.
2. Unggah index.html, style.css, script.js, dan README.txt ke root repository.
   (Tips: kalau repository dibuat publik, jangan unggah README.txt karena berisi jawaban.)
3. Buka Settings > Pages.
4. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
5. Tunggu proses publikasi dan buka URL GitHub Pages yang diberikan.

Semua aset utama memakai emoji/CSS sehingga tidak perlu mengunduh gambar tambahan.
